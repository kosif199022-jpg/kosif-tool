# 3D and 2.5D scenes — المشاهد ثلاثية وشبه ثلاثية الأبعاد

This playbook covers spatial motion: choosing between real 3D (Three.js) and layered 2.5D, isometric worlds, low-poly, camera paths and lenses, basic lighting and materials. Use it whenever a style's categories include `3d`.

يغطي هذا الدليل الحركة المكانية: الاختيار بين ثلاثي الأبعاد الحقيقي (Three.js) والطبقات شبه الثلاثية، العوالم الأيزومترية، المجسمات منخفضة المضلعات، مسارات الكاميرا والعدسات، والإضاءة والمواد الأساسية.

## 1. When to use — متى تستخدمه

Use real 3D only when the camera must travel around or through objects (product turntables, data-centre fly-throughs, worlds). Use 2.5D layering (planes at different depths) for parallax, photo depth and most "3D-feeling" explainers: it is faster, more controllable and renders deterministically with less effort.

**بالعربية:** استخدم ثلاثي الأبعاد الحقيقي فقط عندما يجب أن تدور الكاميرا حول الأجسام أو تعبرها. أما الإحساس بالعمق في الشروحات فالطبقات شبه الثلاثية أسرع وأسهل تحكمًا.

## 2. Visual grammar — القواعد البصرية

- One lighting setup per film: key light at 45°, fill at 30% intensity, rim light for separation.
- One material family: matte (roughness 0.6–0.9) for clay and low-poly; glossy only for hero products.
- Isometric: 30° projection (true isometric 35.264° camera pitch), orthographic camera, grid unit fixed.
- Lens: 35–50 mm equivalent (Three.js fov 40–55°) for natural shots; 85 mm (fov ≈ 24°) for product close-ups.

**بالعربية:** إضاءة واحدة للفيلم (رئيسية بزاوية 45° وتعبئة 30٪ وإضاءة حافة)، عائلة مواد واحدة، الأيزومتري بكاميرا متعامدة، والعدسة 35–50 ملم للقطات الطبيعية.

## 3. Motion mechanics — ميكانيكا الحركة

- Camera moves on smooth splines (CatmullRom) with ease-in-out sine over 2–5 s; never linear starts and stops.
- Dolly speed 0.3–1.2 scene units per second; orbit 10–25° per second for turntables.
- Objects enter with a drop (0.4 s ease-in) + bounce settle (spring damping 12) or rise from below the floor plane.
- 2.5D parallax: layer speed ∝ 1/depth; foreground 1.0, midground 0.5, background 0.15.
- Determinism in Three.js: render with `renderer.render()` inside `seek(t)` only, compute all transforms from `t`, disable `requestAnimationFrame` loops under the renderer, set `preserveDrawingBuffer: true`.
- Depth of field is expensive: fake it with a blurred background layer in 2.5D.

**بالعربية:** الكاميرا على منحنيات ناعمة بتسهيل sine خلال 2–5 ثوانٍ. الدوران 10–25° في الثانية. الأجسام تسقط وتستقر بنابض. في البارالاكس سرعة الطبقة عكس عمقها. في Three.js احسب كل شيء من الزمن داخل `seek(t)` ولا تستخدم حلقة rAF أثناء الرندر.

## 4. Scene recipes — وصفات المشاهد

**A — Product turntable (منصة المنتج الدوارة)**

| start | end | action | easing |
|---|---|---|---|
| 0 s | 0.6 s | product drops onto plinth | ease-in quad + spring |
| 0.6 s | 4.6 s | orbit 90° with slight push-in | ease-in-out sine |
| 2.0 s | 2.4 s | feature callout line draws | ease-out cubic |
| 4.6 s | 6.0 s | hold hero angle | none |

**B — Isometric build (بناء أيزومتري):** tiles rise from the floor in a diagonal wave (40 ms per tile), then buildings extrude (300 ms each), then small agents move along paths.

**C — 2.5D photo push (دفع في صورة):** photo split into 3 layers (sky, subject, foreground), camera pushes 8% over 4 s, layers offset by parallax ratio.

**D — Fly-through (تحليق):** camera follows a spline through 4 waypoints in 6 s, each waypoint aligned to a narration term.

## 5. Implementation — التنفيذ

Three.js seekable scene for `tools/render_html.cjs`:

```js
import * as THREE from 'three';
const renderer = new THREE.WebGLRenderer({ antialias: true, preserveDrawingBuffer: true });
renderer.setSize(1080, 1920); document.body.appendChild(renderer.domElement);
const scene = new THREE.Scene(), cam = new THREE.PerspectiveCamera(45, 1080 / 1920, 0.1, 100);
const box = new THREE.Mesh(new THREE.BoxGeometry(1, 1, 1), new THREE.MeshStandardMaterial({ color: 0x7ee8d2, roughness: 0.7 }));
scene.add(box, new THREE.HemisphereLight(0xffffff, 0x223344, 0.6));
const key = new THREE.DirectionalLight(0xffffff, 1.2); key.position.set(3, 4, 2); scene.add(key);
const ease = (x) => -(Math.cos(Math.PI * x) - 1) / 2;
window.__kosif = { duration: 6, seek(t) {
  const p = ease(Math.min(1, t / 6)), a = p * Math.PI / 2;
  cam.position.set(Math.sin(a) * 4, 1.5, Math.cos(a) * 4); cam.lookAt(0, 0, 0);
  box.rotation.y = t * 0.2; renderer.render(scene, cam);
} };
```

Remotion: use `@remotion/three` (`<ThreeCanvas>`) and drive transforms from `useCurrentFrame()`.

## 6. Arabic and RTL notes — ملاحظات العربية

Do not render Arabic as 3D text geometry from fonts that lack proper shaping; overlay Arabic as HTML/SVG on top of the canvas, or render it to a texture via a 2D canvas with `direction = 'rtl'`.

**بالعربية:** لا تحوّل النص العربي إلى مجسم من خطوط لا تدعم التشكيل؛ ضعه كطبقة HTML/SVG فوق المشهد أو كخامة مرسومة في Canvas باتجاه RTL.

## 7. Audio sync — المزامنة مع الصوت

Camera waypoints align with key terms; object landings with transients; long orbits sit under sustained music or a narration paragraph.

**بالعربية:** نقاط الكاميرا مع المصطلحات المهمة، وهبوط الأجسام مع الضربات، والدوران الطويل تحت موسيقى ممتدة.

## 8. Quality checklist — قائمة الفحص

1. Real 3D justified (else 2.5D)?
2. One lighting setup?
3. Camera moves eased, no linear starts?
4. All transforms computed from t (seekable)?
5. `preserveDrawingBuffer` on for screenshots?
6. Frame render time acceptable?
7. Arabic text overlaid correctly shaped?
8. Materials consistent?
9. No z-fighting or clipping?
10. Final hero frame held ≥ 1.5 s?

## 9. Anti-patterns — أخطاء شائعة

Chrome everything; spinning logos for no reason; motion-sick camera whips; default grey lighting; random lens flares; a 3D scene where a flat illustration would explain better.

**بالعربية:** معادن لامعة لكل شيء، شعارات تدور بلا سبب، كاميرا تسبب الدوار، إضاءة افتراضية رمادية، وهج عدسة عشوائي.
