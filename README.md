# KOSIF TOOL — Motion Graphics Style Atlas

A Claude-readable library of **288 motion style entries**: 243 externally linked PromptsMotion demonstrations plus 45 KOSIF curated style profiles. These are reference-based instructions, not guaranteed pre-built render engines.

Open [visual catalog](index.html) or [style index](STYLE_INDEX.md).
