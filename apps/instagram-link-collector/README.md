# KOSIF Instagram link collector — إضافة كروم لجمع روابط فيديوهات حساب

بتجمع كل روابط الفيديوهات (الريلز) من صفحة أي حساب إنستجرام بتفتحه في كروم، وتنسخها أو تحفظها في ملف `.txt` يتحمّل بأمر واحد.

## التركيب (مرة واحدة)
1. افتح `chrome://extensions` وشغّل **Developer mode**.
2. دوس **Load unpacked** واختار الفولدر ده (`apps/instagram-link-collector`).

## الاستخدام
1. ادخل إنستجرام بحسابك في كروم وافتح صفحة الحساب.
2. دوس أيقونة الإضافة ← **افتح تبويب الريلز** ← **ابدأ الجمع**. سيب التبويب مفتوح؛ ممكن تقفل نافذة الإضافة وترجع لها.
3. **نسخ الروابط** أو **حفظ ملف .txt**.
4. حمّل:
   ```bash
   cd .claude/skills/kosif-superpowers
   python3 scripts/instagram_finder.py get --urls ~/Downloads/instagram-NAME-YYYY-MM-DD.txt
   ```

## الخصوصية والحدود
- مفيش أي طلب لسيرفر تاني: الإضافة بتقرأ الروابط من الصفحة اللي قدامك بس ومش بتلمس الكوكيز.
- صلاحياتها: `activeTab` و`scripting` و`storage` على `www.instagram.com` بس.
- بتنزل بسرعة بني آدم (1.5 لـ2.5 ثانية) وبتقف بعد 5 نزلات من غير روابط جديدة، أو عند الحد (افتراضي 1000، أقصى 5000).
- «فيديوهات بس» بيعتمد على رابط `/reel/`، أو تبويب الريلز، أو أيقونة الريل على المربع. في التبويب الرئيسي ممكن يفوّت فيديو قديم من غير أيقونة، فاستخدم تبويب الريلز.
- لو إنستجرام غيّر شكل الصفحة، الإضافة ممكن تحتاج تعديل.
- التحميل لأغراض المرجع الخاص أو بإذن صاحب المحتوى، وشروط إنستجرام بتمنع إعادة نشر محتوى الغير من غير إذن.
