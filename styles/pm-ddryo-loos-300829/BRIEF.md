## الفكرة
كل ميزة في المكتبة تتحول إلى رسم تخطيطي حي بدلاً من شرح بالكلام: القيم تتحول إلى أشكال تكبر، والكود يظهر بجانب نتيجته البصرية. الأسلوب مثل توثيق أنيق يتحرك: أبيض، خطوط رفيعة، تسميات أحادية المسافة، ولون واحد لكل فصل.

## Concept
Each framework feature becomes a live diagram instead of a sentence: values become shapes that grow, and code sits beside its visual result. It reads like elegant documentation in motion: white canvas, hairlines, monospaced labels and one accent colour per chapter.

## قواعد الحركة
- خلفية بيضاء #f7f7f8 بخطوط شعرية؛ عناوين الفصول أعلى اليسار بخط صغير شبه عريض رمادي داكن #1f1f24 يسبقه رقم الفصل من خانتين.
- لون مميز واحد لكل فصل: بنفسجي #b9a2f5، أحمر #e04a3a، فيروزي #79d7e6، برتقالي #ee4c12 / #f47c4f، أخضر #4fc36b، أزرق #2f7bf2.
- القيم تتحرك كأشكال هندسية: الأحجام تكبر بتباطؤ في النهاية (نحو 600 مللي ثانية) مع فاصل نحو 80 مللي ثانية بين العناصر؛ والمنحنيات تُرسم بأسلوب stroke-dashoffset.
- الكود يظهر كرموز أحادية المسافة؛ والرمز النشط يأخذ شارة تظليل ملونة تنزلق مع تغير القيم.
- الانتقال بين الفصول: بطاقة عنوان بلون مسطح يملأ الإطار (برتقالي أو أسود، نحو 1.5 ث، نص أبيض عريض في الوسط) أو انتقال سريع بضبابية حركة.
- الأكوام متساوية القياس والمربعات المتقلبة بظلال ناعمة؛ ومكونات الواجهة تنبثق بتكبير من 0.95 إلى 1 مع ظهور تدريجي.
- الخط: غروتسك محايد شبيه بـ Inter للواجهة والعناوين، وأحادي المسافة للكود والتسميات؛ وشعار الختام بالأسود مع رقم الإصدار بالأزرق. يوجد مسار صوت لكنه لم يُحلَّل.

## Motion rules
- Canvas white #f7f7f8 with hairline rules; chapter titles top-left in small semibold dark grey #1f1f24 preceded by a two-digit chapter number.
- One accent per chapter: violet #b9a2f5, red #e04a3a, cyan #79d7e6, orange #ee4c12 / #f47c4f, green #4fc36b, blue #2f7bf2.
- Values animate as geometry: sizes grow with an ease-out (~600 ms) and siblings stagger ~80 ms; curves draw on with stroke-dashoffset.
- Code appears as monospaced tokens; the active token gets a tinted highlight pill that slides along as values change.
- Chapter changes: either a full-bleed solid colour title card (orange or black, ~1.5 s, centred bold white sans) or a quick motion-blur whip.
- Isometric stacks and tumbling tiles use soft drop shadows; UI components pop with scale 0.95→1 and fade.
- Type: neutral grotesk (Inter-like) for UI and headings, monospace for code and labels; end card logo uses black wordmark with the version in blue. Audio track present but not analysed.
