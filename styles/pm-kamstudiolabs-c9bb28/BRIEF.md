## الفكرة
الفكرة أن «الخطأ البرمجي» كائن حي لطيف يسكن الكود ويختبئ من المبرمج. الكود لا يُقرأ، بل يُرسم كأشرطة ملونة مستديرة كالأقلام العريضة، فيصبح منظراً طبيعياً تتنقل فيه الحشرة. أدوات المحرر (المؤشر، التحديد، الخط المتعرج، تمييز السطر، الحذف) تتحول إلى صيادين، والحشرة تنجو في كل مرة، وتأتي النهاية بنكتة مكتوبة.

## Concept
The idea is that a software bug is a cute living creature that inhabits the code and hides from the programmer. The code is not readable; it is drawn as rounded marker-like colour bars, so it becomes a landscape for the bug to move through. Editor tools (cursor, marquee, error squiggle, line highlight, delete) turn into hunters, the bug escapes every time, and the ending lands on a written punchline.

- 63-80s: Calm returns: the cursor gives up and drifts away with a loading spinner, the squiggle remains, and the bug settles back into its bracket glowing softly.
- 80-90s: The code dims to black, the camera pulls back to the dark room where only the screen's small glow remains near the silhouette, then a cut to a bold condensed cream title card.
