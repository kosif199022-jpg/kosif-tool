# Kosif — نظام "كتاب كافيه" البصري

ثيم موحّد يمتدّ عبر الرئيسية والمراجعة والمكتبات والقارئ والمعايير وتحليل المبيعات.
مبني على `#FBF4E1` — لون الثيم المعلن في kitabcaffe.com — مع سلّم قهوة للحبر وسلّم ذهب للتأكيد.

---

## التركيب

```bash
# ١. انسخ الملفات الجديدة فوق جذر المستودع
#    public/kosif-kitab-theme.css
#    public/kosif-kitab-theme.js
#    public/fonts/*.woff2
#    scripts/apply-kitab-theme.mjs
#    scripts/wire-kitab-theme.mjs

# ٢. رحّل الألوان في كل ملفات CSS والصفحات
node scripts/apply-kitab-theme.mjs

# ٣. أوصِل الثيم بنقاط الدخول (رؤوس الصفحات، SW، الحافة)
node scripts/wire-kitab-theme.mjs

# ٤. تحقّق
npm run check
```

الخطوتان ٢ و ٣ **متكرّرتا الاستدعاء بأمان** — التشغيل الثاني لا يغيّر شيئًا.
شغّلهما بعد أي `git pull` يجلب ملفات CSS جديدة.

```bash
node scripts/apply-kitab-theme.mjs --check   # يفشل إذا عادت ألوان قديمة
node scripts/wire-kitab-theme.mjs  --check   # يفشل إذا انفصل التوصيل
```

اقتراح: أضف السطرين إلى `scripts.check` في `package.json` كبوّابة انحراف بصري.

## التراجع

```bash
node scripts/apply-kitab-theme.mjs --revert   # يستعيد الألوان من .kitab-backup/
```

نسخ ما قبل الترحيل محفوظة في `.kitab-backup/` (٢١ ملفًا). أضفها إلى `.gitignore`.
التوصيل يُزال يدويًا: احذف كتل `kosif-kitab-theme` من الرؤوس و`sw.js` و`suite-edge.js`.

## الخطوط

مستضافة محليًا في `public/fonts` — الهَب يُقدَّم تحت `default-src 'self'`، فأي CDN خارجي محجوب.
مأخوذة من fontsource 5.3.0 مع `unicode-range` دقيق وتقسيم عربي/لاتيني.

| الخط | الدور | الأوزان |
|---|---|---|
| Alexandria | العناوين والبِنية | 500 / 700 / 900 |
| IBM Plex Sans Arabic | المتن والأرقام | 400 / 500 / 600 / 700 |
| Amiri | العلامة والاقتباس | 400 |

الأرقام تستخدم `tabular-nums` إلزاميًا في الجداول والخلايا المالية:
عمود الميزان لا يزحف على جاره.

## العنصر المميّز — شريط العلّامة

شريط ذهبي مشقوق الطرف يجيب عن سؤال «أين أنا الآن»: التبويب المفتوح (`.tab.active`،
`.tab[aria-selected="true"]`) والبطاقة عند التمرير (`.module`، `.book`).
لأي عنصر آخر، أضف الصنف `kc-ribbon`.

شريط تبديل الأقسام (`#kosif-suite-switcher`) **مستثنى عمدًا** — ارتفاعه ٤٢ بكسل
والشريط ٢٦، فيبقى بتعبئته الذهبية بدل أن يفيض.

## سلطة الثيم

عدّة طبقات في Kosif تحقن CSS بعد أول رسم (Phase-B/D، canva، analytics-3d،
وسيط قارئ الثروة). أيٌّ منها لو وصلت بعد الثيم لأعادت اللوحة القديمة في منتصف
الجلسة — وهو بالضبط الخلل المختلط الذي كُتب `suite-shell.js` لعلاجه على `/audit`.

`kosif-kitab-theme.js` يثبّت الورقة آخر `<head>` عبر `MutationObserver` + أربع
محاولات مؤجّلة، على **كل** المسارات لا `/audit` وحده.

## الوضع الليلي

`prefers-color-scheme: dark` يحوّل اللوحة إلى «مقهى الليل»: `#171009` ورقًا،
`#211710` أسطحًا، `#F0E4CB` حبرًا، والذهب يرتفع إلى `#D9A441` ليحافظ على التباين.

## ملاحظة على الدقة

CSS الموقع المرجعي غير قابل للقراءة عبر أدوات الجلب (تُعيد النص فقط).
المرساة `#FBF4E1` **مؤكَّدة** من وسم `theme-color` المنشور؛ بقية السلّم واختيار
الخطوط **استنتاج مبني على الدور والهوية**، لا مطابقة بصرية.
