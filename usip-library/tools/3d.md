### `blender-api-audit` — تدقيق واجهة بايثون في Blender / Blender Python API audit

| الحقل | القيمة |
|---|---|
| المسار | `scripts/blender_api_audit.py` (جذر: skill) |
| المجال | `3d` |
| الدليل | `tested-here` |
| العائلات | `software-investigation`, `3d-spatial` |

**ما تفعله:** يحلّل كل ملفات ‎.py في مجلد سكربتات Blender أو إضافاته أو شيفرته المصدرية تحليلًا ثابتًا بوحدة ast في بايثون، دون استيراد أي ملف أو تشغيله. يعدّ أصناف Operator وPanel وMenu وPropertyGroup وGizmoGroup من bpy.types واستدعاءات bpy.ops، ويصنّف الملفات في مجموعات موضوعية حسب أسمائها، ثم يطبع ملخصًا بصيغة JSON.

**What it does:** Statically parses every .py file under a Blender scripts, addon or source folder with Python's ast module, without importing or running anything. It counts bpy.types Operator, Panel, Menu, PropertyGroup and GizmoGroup classes, bpy.ops calls and topic groups by file name, and prints a JSON summary.

#### متى تُستدعى

- «افحص سكربتات بايثون اللي مع Blender من غير ما تشغّلها»
- «What bpy operators does this Blender addon folder call?»
- «عدّ الـ Operators والـ Panels في مجلد إضافات بلندر»
- «Statically audit Blender's bundled Python API usage before building a bridge»

#### الأوامر

- **--help**: Shows usage: one positional source folder and an optional --output.
  - `python3 scripts/blender_api_audit.py --help`
- **audit**: Parses all .py files under the folder (at most 3,000; files over 2 MB are skipped) and prints a JSON summary without the samples or bpy.ops lists.
  - `python3 scripts/blender_api_audit.py ./blender-scripts/`
- **audit --output**: Also writes the full report (up to 45 samples and the top 120 bpy.ops calls) to a new file. It refuses an existing file or a path inside the scanned tree, and the output folder must already exist.
  - `python3 scripts/blender_api_audit.py ./blender-scripts/ --output ./out/blender_api_audit.json`

#### المتطلبات والأمان

- الأمان: writes-files
- الموافقة: Reads every .py file under the folder given (confirm it is the user's Blender install, addon or source tree); it never imports or runs them, and --output writes one new JSON file without overwriting.
- الحدود: It produces static AST counts of bpy classes and bpy.ops calls in .py files only (at most 3,000 files); it does not run Blender, read C/C++ or prove runtime behaviour, and its topic counts are file-name substring heuristics.

### `blender-bridge` — جسر Blender الآمن / Safe headless Blender bridge

| الحقل | القيمة |
|---|---|
| المسار | `scripts/blender_bridge.py` (جذر: skill) |
| المجال | `3d` |
| الدليل | `tested-here` |
| العائلات | `3d-spatial`, `engines-render-pipeline`, `formats-platforms` |

**ما تفعله:** يتحقق من مشهد JSON محدود بصيغة kosif.blender.v1، ثم يشغّل Blender المثبّت مسبقًا لدى المستخدم في الخلفية (بإعدادات المصنع ومع تعطيل التنفيذ التلقائي) عبر blender_worker.py لإنتاج صورة PNG أو ملف ‎.blend قابل للتعديل أو ملف ‎.glb متحرك، أما الأمر doctor فيكتفي باكتشاف Blender.

**What it does:** Validates a bounded kosif.blender.v1 JSON scene and, when the user already has Blender installed, runs it headless (factory startup, autoexec disabled) through blender_worker.py to produce a PNG still, an editable .blend or an animated .glb; doctor only detects Blender.

#### متى تُستدعى

- «عندي Blender متثبت، اعمل منه رندر PNG للمشهد ده»
- «أبي ملف .blend أقدر أعدّله من مشهد JSON»
- «هل Blender موجود على هذا الجهاز؟»
- «render this JSON scene with my installed Blender to a .blend or .glb»
- «check whether Blender is installed before a 3D job»

#### الأوامر

- **doctor**: Reports whether a `blender` executable is on PATH and the supported formats; never downloads or installs and does not render.
  - `python3 scripts/blender_bridge.py doctor`
- **render (GLB)**: Validates the scene, runs Blender in the background with blender_worker.py and exports an animated .glb; prints JSON with format, bytes, sha256 and object_count.
  - `python3 scripts/blender_bridge.py render --scene templates/blender-demo.json --output ./out/scene.glb`
- **render (.blend)**: Saves an editable Blender project of the same scene.
  - `python3 scripts/blender_bridge.py render --scene templates/blender-demo.json --output ./out/scene.blend`
- **render (PNG, explicit Blender)**: Renders a still with the Blender executable at the given file path instead of the one on PATH.
  - `python3 scripts/blender_bridge.py render --scene templates/blender-demo.json --output ./out/still.png --blender /opt/blender/blender`

#### المتطلبات والأمان

- binaries: blender
- الأمان: runs-external-programs
- الموافقة: Installing Blender needs user approval (the tool never downloads it); render executes the user's local Blender binary, or the one passed with --blender.
- الحدود: Fixed camera, one area light and location-only keyframes on primitives; doctor only detects Blender, and the repo records no real Blender render through this bridge.

### `blender-cinema` — رندر سينمائي بـBlender Cycles / Blender Cycles cinematic renders

**What it does:** Drives a local Blender (or the pip bpy module) to render cinematic Cycles stills or animations from five presets (product-hero, golden-hour, noir-volumetric, neon-night, anamorphic-epic) with light rigs, depth of field, fog, AgX looks, compositor finishing and camera moves, optionally around the user's model, and can dump a live Blender capability inventory.

- **doctor**: Finds Blender (KOSIF_BLENDER, PATH, ~/KOSIF-Tools/Blender*, Program Files, /Applications, /usr/bin, /snap/bin, ~/blender*) and runs it with -v to read its version, or else a Python that can import bpy (KOSIF_BPY_PYTHON or the current one), plus ffmpeg; prints ready and an install hint.   - `python3 scripts/blender_cinema.py presets`
- **inventory**: Runs Blender to write a JSON inventory of operators, node types, sky/lens/codec enums, Cycles settings, add-ons and compute devices into an existing folder; without Blender it currently stops with a Python traceback.
  - `python3 scripts/blender_cinema.py inventory -o ./out/blender-inventory.json`
- **render (still)**: Builds the preset set, lights, placeholder subject (Suzanne), camera and compositor, then renders one PNG with Cycles and measures it.
  - `python3 scripts/blender_cinema.py render --preset neon-night --res 1280x720 --quality preview -o ./out/shot.png`
- **render (own model, final, editable)**: Imports the user's model, fits it into a 2 m box on the floor, renders at 512 samples and also saves the editable compressed .blend.
  - `python3 scripts/blender_cinema.py render --preset product-hero --model ./model.glb --quality final --save-blend ./out/hero.blend -o ./out/hero.png`
- **render (camera move animation)**: Renders an animated camera move (orbit, dolly-in, crane-up, vertigo, handheld) with motion blur and encodes it to H.264 MP4 with ffmpeg, or copies the frames to a folder when ffmpeg is missing.
  - `python3 scripts/blender_cinema.py render --preset golden-hour --frames 72 --fps 24 --move orbit -o ./out/turntable.mp4`

- optional: bin:ffmpeg, pip:Pillow, pip:bpy
- الأمان: runs-external-programs
- الموافقة: Installing Blender or running `pip install bpy` (what doctor suggests) needs user approval; --model loads a user 3D file into Blender, so use only files the user owns or trusts; final quality or long animations can keep the CPU/GPU busy for a long time.
- الحدود: The look comes from five fixed presets around a placeholder or imported model, so it does not create characters, rigs or story animation, and nothing renders without Blender or bpy.
