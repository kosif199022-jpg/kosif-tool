# معايير الجودة وسلالم التعافي / quality bars and recovery ladders

> مولّد من `data/usip_intelligence.json` (الملاحق A25 وA27 وA29). [الفهرس](../README.md)

## فيديو وموشن ومونتاج (`video`)

**خانات الاستقبال:**

- المقاس والمنصة: افتراض مكتوب ← 9:16 لمنصات المقاطع القصيرة
- المدة: افتراض مكتوب ← مدة الصوت المرفوع، وإلا 30 ثانية
- الصوت المصدر: سؤال بإجابة مقترحة ← بلا صوت مرفوع: موسيقى مرخصة هادئة أو صمت، يُسأل عنها
- اللقطات والأصول: افتراض مكتوب ← لقطات مجانية مرخصة مع تسجيل رخصة كل لقطة
- الأسلوب البصري: افتراض مكتوب ← أسلوب واحد متسق يقترحه التقرير
- النص الظاهر واللغة: افتراض مكتوب ← عربية RTL بلغة الطلب

**معايير الجودة:**

- إلزامي: المدة والمقاس وfps مطابقة بالقياس ← tools/verify_video.py أو ffprobe
- إلزامي: صوت المستخدم منسوخ بلا تعديل (MD5 مطابق) ← ffmpeg -f md5
- جودة: تزامن الكلمات ضمن ±2 إطار من words.json ← سجل seek
- إلزامي: العربية متصلة الحروف وصحيحة الاتجاه ← لوحة لقطات
- إلزامي: حركة حقيقية (كاميرا أو رسم أو تحويل) لا شرائح ثابتة ← لوحة لقطات كل ثانيتين
- جودة: النص داخل المنطقة الآمنة للمنصة ← لقطة بإطار المنطقة الآمنة
- إلزامي: رخصة كل لقطة وموسيقى وخط مسجلة ← rights.json أو جدول المصادر
- جودة: معاينة رخيصة قبل الرندر الكامل ← render_html.cjs --preview

**المراحل:** قياس الصوت والأصول ← ستوريبورد ← بناء المشهد ← معاينة رخيصة ← رندر ← تحقق ← تسليم

## صوت وتفريغ وموسيقى (`audio`)

**خانات الاستقبال:**

- الملف المصدر: مدخل حاجب ← لا يُفترض: المدخل مطلوب
- اللغة واللهجة: افتراض مكتوب ← تُكتشف من الملف وتُذكر
- صيغة المخرج: افتراض مكتوب ← نص مع توقيت الكلمات words.json

**معايير الجودة:**

- إلزامي: التسجيل الأصلي محفوظ وأي معالجة على نسخة ← MD5 قبل وبعد
- جودة: الجهارة والذروة مقيسة ومبلغة ← ffmpeg ebur128
- جودة: توقيت الكلمات متسق مع الموجة ← عينات استماع عند 5 نقاط
- إلزامي: الآيات من المصحف لا من التفريغ ← مطابقة مع نص المصحف

**المراحل:** قياس الملف (مدة، جهارة) ← معالجة على نسخة ← تفريغ أو مزامنة ← عينات استماع ← تسليم

## صور وتصميم وشعار (`image`)

**خانات الاستقبال:**

- المقاس والاستخدام: افتراض مكتوب ← مقاس منصة الاستخدام المذكورة
- الهوية والألوان والخطوط: افتراض مكتوب ← لوحة ألوان مقترحة بتباين WCAG AA
- صيغة قابلة للتعديل: افتراض مكتوب ← SVG أو مصدر قابل للتعديل مع PNG

**معايير الجودة:**

- إلزامي: مقروء بمقاس صغير (اختبار التصغير) ← تصغير إلى 15%
- إلزامي: تباين النص ≥ 4.5:1 ← حساب نسبة التباين
- إلزامي: رخصة كل خط مؤكدة من مصدره ← ملف الرخصة
- إلزامي: أصالة بلا نسخ لعمل آخر ← مقارنة بالمراجع
- إلزامي: تشكيل الحروف العربية واتصالها صحيح ← رندر فعلي ونظرة

**المراحل:** المقاس والهوية ← ثلاث مصغرات ← تطوير المختارة ← اختبار التصغير والتباين ← تصدير قابل للتعديل + PNG

## كود وتطبيقات ومواقع (`code`)

**خانات الاستقبال:**

- اللغة والإطار: افتراض مكتوب ← لغة المستودع الموجود، وإلا Python أو HTML/JS بلا اعتماديات
- أين يعمل: افتراض مكتوب ← المتصفح أو سطر الأوامر حسب المخرج
- مستودع أو ملفات موجودة: سؤال بإجابة مقترحة ← مشروع جديد مستقل
- متى يكون ناجحًا: افتراض مكتوب ← الاختبارات الموجودة تمر + اختبار لكل سلوك جديد

**معايير الجودة:**

- إلزامي: الاختبارات الموجودة تمر قبل التعديل وبعده ← أمر الاختبار
- إلزامي: اختبار لكل سلوك جديد أو خطأ مُصلح ← الاختبار الجديد يفشل قبل الإصلاح
- إلزامي: لا أسرار ولا مسارات جلسة في الشيفرة ← بحث أنماط الأسرار
- جودة: يطابق أسلوب الكود المحيط وتسمياته ← مراجعة الفرق
- جودة: طريقة تشغيل مكتوبة ومجرَّبة ← تشغيل الأمر المكتوب
- جودة: الفرق أصغر ما يحقق الطلب بلا إعادة كتابة غير مطلوبة ← git diff --stat
- جودة: المدخل الخاطئ يعطي خطأ واضحًا لا انهيارًا صامتًا ← تشغيل بمدخل خاطئ

**المراحل:** قراءة الكود والاختبارات ← إعادة إنتاج أو اختبار جديد ← أصغر تغيير ← الاختبارات ← مراجعة الفرق ← فرع وPR

## بيانات وجداول ورسوم (`data`)

**خانات الاستقبال:**

- مصدر البيانات: مدخل حاجب ← لا يُفترض: البيانات مطلوبة أو مصدر عام مسمى
- السؤال الذي تجيب عنه البيانات: سؤال بإجابة مقترحة ← وصف عام: توزيع واتجاه وأعلى خمس فئات

- جودة: القيم المفقودة والشاذة معالجة ومذكورة ← عدّ القيم الفارغة

**المراحل:** فحص الملف ← تنظيف موثق ← حساب بسكربت ← تسوية المجاميع ← رسم يناسب السؤال ← تسليم مع السكربت

**المراحل:** السؤال والنطاق ← مصادر بتواريخها ← حقائق بمراجعها ← تركيب ورأي مخالف ← تدقيق ادعاء ← دليل ← تسليم

## التعافي: اعتمادية مفقودة (`missing_dependency`)

الميزانية: 2 · العلامات: ModuleNotFoundError, command not found, No such file, not installed, غير مثبت

**التشخيص:**

1. سمِّ الاعتمادية بالضبط (حزمة، برنامج، خط، نموذج)
2. افحص وجودها بأمر واحد (import أو --version أو ls)
3. افحص هل يوجد بديل مثبت يؤدي الشيء نفسه

**الإصلاح:**

1. ثبّت محليًا في بيئة العمل إن كان مجانيًا ومسموحًا (pip --user أو venv أو npm محلي)
2. استعمل البديل المثبت وسجّله استبدالًا

**البديل:** مسار المكتبة القياسية أو أداة أخرى من نفس المجموعة

**التصعيد:** تثبيت نظامي أو مدفوع أو يحتاج مفتاحًا: توقف واسأل

## التعافي: نوع مدخل خاطئ (`wrong_input_kind`)

الميزانية: 2 · العلامات: Invalid data, codec, unsupported format, decode error, صيغة غير مدعومة

**التشخيص:**

1. افحص المدخل الفعلي (file، ffprobe، أول بايتات، ترميز النص)
2. قارن نوعه بما تتوقعه العقدة التالية في الرسم

**الإصلاح:**

1. أضف محوّلًا صريحًا بين العقدتين (مثلًا ffmpeg لتحويل الصيغة) واحفظ الأصل كما هو
2. صحّح نوع الحافة في الرسم إن كان الخطأ في التخطيط

**البديل:** اطلب المدخل بالصيغة الصحيحة مع أمر تحويل جاهز

**التصعيد:** إن كان التحويل يفقد جودة أو بيانات: اسأل قبل التحويل

## التعافي: جودة دون العتبة (`quality_below_threshold`)

الميزانية: 3 · العلامات: below threshold, FAIL, drift, out of sync, blurry, دون العتبة

**التشخيص:**

1. أي معيار فشل وبكم (المقيس مقابل العتبة)
2. هل العتبة نفسها صحيحة ومقيسة بالأداة الصحيحة
3. هل السبب في المدخل أم في المعالجة أم في القياس

**الإصلاح:**

1. عالج السبب الأكبر وحده ثم أعد القياس
2. خفّض الطموح في المعيار غير الإلزامي فقط وبإعلان

**البديل:** المنهج البديل المكتوب للمرحلة في الخطة

**التصعيد:** معيار إلزامي لا يتحقق بعد البديل: توقف وأبلغ بالأرقام

## التعافي: تجاوز الوقت (`timeout`)

الميزانية: 2 · العلامات: timed out, Timeout, killed, took too long, انتهت المهلة

**التشخيص:**

1. قس زمن وحدة واحدة (إطار، ملف، طلب) واضربه في العدد
2. حدد هل الاختناق في المعالج أم الشبكة أم القرص

**الإصلاح:**

1. قسّم العمل دفعات قابلة للاستئناف مع نقاط حفظ
2. خفّض الدقة في المعاينة وأبقِ الكاملة للتسليم
3. شغّل في الخلفية مع مراقبة لا حلقة انتظار

**البديل:** معاينة قصيرة تمثل النتيجة ثم قرار المستخدم في الكامل

**التصعيد:** ما يتجاوز زمن الجلسة أو يحتاج عتادًا مدفوعًا: اسأل

## التعافي: صلاحية مرفوضة (`permission_denied`)

الميزانية: 1 · العلامات: Permission denied, 403, 401, EACCES, denied, مرفوض

**التشخيص:**

1. من رفض: نظام الملفات أم الخدمة أم المستخدم في نافذة الإذن
2. هل الرفض قرار مستخدم (لا تعِده كما هو) أم إعداد

**الإصلاح:**

1. اكتب في مسار مسموح (مجلد مؤقت أو مجلد العمل)
2. استعمل الطريق الموثق للمنصة لطلب الوصول

**البديل:** سلّم الأمر جاهزًا ليشغّله المستخدم بنفسه

**التصعيد:** لا تتجاوز أي رفض بحيلة؛ اشرح ما يلزم وانتظر

## التعافي: رخصة تمنع (`license_blocked`)

الميزانية: 1 · العلامات: license, copyright, rights, All rights reserved, رخصة, حقوق

**التشخيص:**

1. اقرأ الرخصة من مصدرها الأصلي
2. حدد ما تسمح به بالضبط (استخدام تجاري، تعديل، نسب)

**الإصلاح:**

1. استبدل الأصل بآخر مرخص ترخيصًا متوافقًا وسجّل المصدر
2. اربط وانسب بدل النسخ

**البديل:** أصل أصلي تصنعه أنت (رسم بالكود، صوت مولّد محليًا)

**التصعيد:** أصل يصر عليه المستخدم ورخصته تمنع: اشرح ولا تنسخ

## التعافي: خطأ أداة (`tool_error`)

الميزانية: 3 · العلامات: Traceback, Error, exit code, segfault, خطأ

**التشخيص:**

1. اقرأ آخر سطر في الخطأ ثم أول سطر من كودك فيه
2. أعد إنتاج الخطأ بأصغر أمر ممكن
3. فرضيات ثلاث على الأقل، واختبار يفصل بينها

**الإصلاح:**

1. أصلح السبب المثبت وحده، ثم شغّل الاختبار المتعلق
2. حوّل إعادة الإنتاج إلى اختبار يبقى

**البديل:** أداة أخرى أو مسار يدوي للمرحلة نفسها

**التصعيد:** خطأ في أداة خارجية لا تملكها: بلّغ بإعادة الإنتاج ولا تخفه

## التعافي: سبب آخر (سوء فهم الطلب، فقدان السياق، تعارض المواصفات، نتيجة متقلبة) (`other`)

الميزانية: 2 · العلامات: unexpected, flaky, mismatch, غير متوقع

**التشخيص:**

1. صنّف: هل فهمتُ الطلب خطأ؟ هل فقدتُ سياقًا (ملخص، جلسة جديدة)؟ هل المواصفات متعارضة؟ هل النتيجة متقلبة بين تشغيلين؟
2. ارجع إلى بطاقة الطلب والمعايير المكتوبة

**الإصلاح:**

1. سوء فهم: أعد صياغة الطلب بسطر واعرضه قبل إعادة العمل
2. فقدان سياق: أعد قراءة الملفات والسجل لا الذاكرة
3. تعارض: طبّق ترتيب الأولوية واذكره
4. تقلب: ثبّت البذرة والإصدارات وشغّل مرتين

**البديل:** أصغر ناتج صحيح مؤكد مع قائمة ما بقي

**التصعيد:** تعارض يغيّر الهدف: قرار المستخدم

## سلم التحقق / verification ladder

- V0: لم يُنتج شيء بعد ← `PLAN_ONLY`
- V1: كُتب الناتج ولم يُشغّل أو يُفتح ← `PLAN_ONLY`
- V2: شُغّل أو فُتح بلا خطأ ظاهر (لم يُقس معيار) ← `EXECUTED_UNVERIFIED`
- V3: بعض المعايير مقيسة بأداة ودليل ← `PARTIALLY_VERIFIED`
- V4: كل المعايير مقيسة بأداة ودليل ← `DONE_VERIFIED`
- V5: V4 + مراجعة مستقلة أو مقارنة بخط أساس ← `DONE_VERIFIED`
