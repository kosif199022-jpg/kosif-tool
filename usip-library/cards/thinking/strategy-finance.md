| نطاق الدليل | `none` |
| الرخصة | غير مذكورة في السجل: تُؤكَّد من المصدر قبل التسليم |

**ما هي:** لا توصية بلا بدائل: ثلاثة خيارات مختلفة حقًا، أحدها «لا نغير شيئًا» يُقيَّم بجدية. — No recommendation without alternatives: three genuinely different options, one of them 'change nothing', evaluated seriously.

**متى:** strategy, build-vs-buy, pricing, hiring, any important decision

**كيف:** Frame first: the decision, who it affects, the outcome wanted, constraints, horizon. Then options A/B/C + do-nothing in a table: cost, benefit, reversibility, time to signal, main risk. Options that are the same idea in three sizes do not count.

**التثبيت:** لا خطوة تثبيت مسجلة

**الوسوم:** decision · options · alternatives · do nothing · قرار · بدائل · استراتيجية

#### 1. الاستقبال (A25)

- العملة: افتراض مكتوب ← عملة الطلب أو المستخدم، مكتوبة على كل رقم
- القواعد المرجعية: سؤال بإجابة مقترحة ← يُذكر المعيار المفترض صراحة
- الفترة: افتراض مكتوب ← الفترة الواردة في المدخل
- لا تُفترض أبدًا: مادة الإنتاج نفسها، والإذن بخطوة مدفوعة أو منشورة أو لا رجعة فيها، والهوية والحقوق.

#### 2. الجاهزية والشارة (A28)

- لا متطلبات مسجلة؛ افحص المسار والأداة بـ `hub.py doctor` قبل الشارة.
- الوضع 1: شارة «هنا الآن» بعد الفحص، لا 📄 الكتالوج تلقائيًا · الوضع 2: `كتالوج: 📄 · هنا: غير مفحوص` · الوضع 3: بلا شارة ولا معرّف.

#### 3. موضعها في الخطة (A26)

- عقدة منمّطة: المدخل `dataset` ← المخرج `report`، والمنفّذ `method:PROD-01` حتى تُربط بأداة مختبرة (`fusionforge.py bind`).
- لا أداة مسجلة تخدم عائلتها: التنفيذ بالمكتبات أو بأداة من مجموعة أخرى.
- مراحل النوع: المدخلات والمعيار ← حساب حتمي بالأعداد الصحيحة ← تسوية ← مراجعة المعالجة بمعيارها ← تسليم.
- إن اختلف نوع مدخلها عن مخرج العقدة السابقة فمحوّل صريح بينهما، والخط ينتهي بعقدة تحقق قبل التسليم.

#### 4. بوابة التحقق (A27)

- إلزامي: كل مبلغ من حساب حتمي (كود) لا تقدير ← سكربت
- إلزامي: المبالغ بأصغر وحدة (هللة/قرش) أعدادًا صحيحة ← الحساب بالأعداد الصحيحة
- إلزامي: المجاميع والأرصدة متوازنة ← ميزان مراجعة
- جودة: كل معالجة مربوطة بمعيارها ← حاشية
- جودة: حدود المشورة المهنية مكتوبة حين يلزم ← سطر تنبيه

#### 5. التعافي (A29)

| نطاق الدليل | `repo` |
| الرخصة | BSD-3-Clause |

**ما هي:** حدّد الافتراضات القليلة التي لو أخطأت لتغيّر القرار، واحسب عتبتها بالكود لا بالتخمين. — Find the few assumptions that would change the decision if wrong, and compute their thresholds in code, not by guesswork.

**متى:** any plan resting on estimates (demand, price, cost, conversion)

**كيف:** List the assumptions; for each, solve for the value at which the preferred option stops winning (sympy.solve of profit_A = profit_B, or break-even = 0). Compare the threshold with the evidence. Related run: break-even Q = 6000 and p* = 60 were solved exactly with sympy (proofs/general-data), but no A-vs-B flipping threshold has been computed here yet, so this method is 📄.

**التثبيت:** pip install sympy
