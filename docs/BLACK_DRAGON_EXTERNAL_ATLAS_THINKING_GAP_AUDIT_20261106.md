## Other counts not proof of coverage

- The internal `kosif-dragon-mind/data/books_thinking.json` has **936 catalog metadata records**, not 936 full books read or working methods. Independently review contents/rights and extract methods before any new count.
- The Atlas mirror README explicitly says third-party content was **not line-by-line reviewed**, so listing a skill is not proving that its code or dependencies work.
- The name-level deduplication of 25 repeated groups across 404 internal records is not a semantic equivalence audit.
- A first comparison across these named sources establishes **at least one substantial external inventory not covered by the fixed 486-record source enumeration**. It does not yield the total number of unique missing thinking methods.

## To earn the statement "all thinking is included"

1. Obtain and freeze a full external Atlas index snapshot with checksum, index version/commit, and pagination or byte-verified parse. The current selected-index retrieval was too large to inspect as a whole; keyword search results are only samples.
2. Classify every candidate skill into: genuinely new cognitive method; more detailed procedure for an existing method; duplicate; operational orchestration; reference-only; unsafe/unavailable dependency; or unrelated domain-specific tool.
3. Derive *canonical cognitive lenses* from full method definitions, not names alone. Preserve source IDs, citations, warnings, contextual applicability and executable state.
4. Assign each unique lens/protocol to one of the 12 current council seats (secondary roles allowed), with no extra rights seat or fixed artistic quorum.
5. Add reconciliation tests: index entries assessed, unmatched entries explained, semantic duplicates attributed, source changes detected, no executable claims without runner receipts.
6. Only after an independently verified debate and an end-to-end media preview should the new council be described as fully functional.
