# KOSIF Innovation & Arabic Font Fidelity — 50-source research index

This index describes **50 separate GitHub repositories (26 typography/glyph + 24 invention/creative systems)** discovered from GitHub searches and direct lookups on 2026-10-18. A repository's presence is not proof of quality, safety, license compatibility or deployment. **No third-party code or executable has been silently installed.**

## Ranked technical building blocks
- **FontTools:** glyph cmap, name metadata, GSUB/GPOS, variable axes; practical core for structured font inspection.
- **HarfBuzz:** proper Arabic shaping and ligature/diacritic handling, essential before measuring visual similarity.
- **FontForge / Fontra:** authoring/editing actual font outlines, not merely raster guessing.
- **Arabic family/classification experiments:** research prototypes; require benchmarks on representative text and style.
- **REA (morluto/rea v6.7.0 at inspection):** evidence-backed application and browser observations; separate permissioned upstream CLI/MCP integration, not a general font classifier.
- **TRIZ skill families:** contradictions, IFR, inventive principles, resource substitution, alternative generation, falsification.
- **KOSIF Jumuah uploaded kit:** OFL-derived Amiri Arabic + Bodoni Moda Latin/figures, Regular/Bold; observed font has Arabic GSUB+GPOS and 1,309 supported code points. Metadata and build recipe reviewed locally; **binary font files intentionally not copied to the repository by this integration**.

## Quality rubric
Candidate selection is evidence-driven: license checked for the exact code/assets, maintained and actually runnable, relevant to the task, tested baseline, performance and Arabic coverage, no unauthorized target inspection. A project reference is not proof its execution path is available.

## Honest fidelity acceptance
Font matching can rank **candidate font renderings**, not identify an exact proprietary font without proof. For Arabic sample strings evaluate connected glyphs, ligatures, kerning/marks, tatweel, diacritics, mixed numbers, and RTL. Normalize scale and align masks before IoU/difference; compare more than one phrase and crop from original frames. Detect and report false positives where two fonts look alike for one word but diverge on another. User-supplied font software still requires license permission before modification or distribution.

## REA full-capability route (without copying runtime)
See [REA current integration](rea-reverse-engineering.md) and [REA capability families](rea-upstream-capabilities.md). CLI/MCP installation, Ghidra/Hopper, browser CDP and device observation remain **separately authorized**. The KOSIF bridge uses static safe plans and receipts, while the full upstream REA CLI and skill are the source of truth for supported commands.

## Evaluation protocol
Baseline: existing REA bridge and creative-intelligence tests. Candidate: addition of a readable 50-repo registry, testable TRIZ-like ideation and a font-fidelity CLI, plus upstream REA mapping. Positive triggers: Arabic font matching, reference typography/brand creation, technical invention, legal REA artifact analysis. Negatives: arbitrary image tasks do not trigger native reverse engineering; simple text prompts do not auto-download 50 repos; untrusted external binaries require opt-in; licensed font assets must not be republished. Compare in CI and test RTL rendering separately on a host with libraqm.
