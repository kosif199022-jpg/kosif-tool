# Unified Cinematic — audio-clocked photo, drawing and camera workflow

**One CLI, five original KOSIF/installed components:**
1. `audio_cue_mapper.measure_wav`: reads real 16-bit uncompressed PCM WAV, reports duration and amplitude onset **candidates**. Does **not** infer verified musical beats, BPM, lyrics, phonemes or emotion.
2. `app_studio.py`: processes a local authorized background photo with explicit, finite exposure and named effects.
3. `unified_draw.py`: compiles mixed strokes and shapes into layer animation.
4. `creative_paint.py` via `unified_media.compose`: draws transparent time-varying vector/text layers over each photo frame, including selected onset-driven scale pulses; does not modify existing manual keyframes.
5. `FFmpeg`/Pillow: 2D crop-pan/push/pull camera, entry/exit fades, H.264 video with WAV source mixed into an AAC audio stream.

## Quick start

From `.claude/skills/kosif-superpowers/`:

```powershell
python scripts/unified_cinematic.py doctor
python scripts/unified_cinematic.py render --photo templates/unified-media-demo-photo.png --scene templates/unified-draw-motion-demo.json --audio YOUR_LOCAL_16BIT_PCM.wav --output ./cinematic.mp4 --fps 12 --camera push-in --fade-frames 2 --pulse-element 3 --effect develop --exposure 0.3
python scripts/test_unified_cinematic.py
```

**Use a new output filename.** Input audio must be an existing local 16-bit PCM WAV (mono/stereo, sample rate 8–192kHz) whose duration is 0.1–30 seconds, with a maximum of 300 rendered video frames. The audio file is read-only and provides the timeline's duration. Video is frame-quantized, with less than 1/FPS duration rounding; the exported audio is **encoded to AAC**, so it is not sample-identical to the source. The source WAV is not edited. No word-level forced alignment is claimed.

Camera choices: `static`, `push-in`, `pull-back`, `pan-right` (2D simulated camera movement against the photo background, not a physical 3D camera). `--fade-frames` optionally fades visuals to/from black; it does not change source audio. `--pulse-element N` is optional and maps amplitude transient candidate timestamps onto scale animation of one 1-based unkeyframed layer. It does **not** establish beat accuracy or musical synchronization quality. If the layer already has keyframes, the tool refuses to replace them.

Photo options: `none`, `develop`, `ink-sketch`, `pencil-sketch`. Existing KOSIF original source code only. Input imagery must be authorized local file and passes size checks. No proprietary commercial code imported, no original soundtrack synthesis, no photorealistic 3D or character video generation, no background network calls.
