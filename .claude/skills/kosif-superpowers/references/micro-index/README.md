# الفهرس الدقيق / Micro index

سطر واحد لكل قدرة وأداة وقدرة خارقة: أين تعيش، وشارتها، ومستلزماتها، وقدرتها الخارقة، وأدوات عائلتها، وفصلها وبطاقتها. مولَّد بأمر `python3 scripts/micro_index.py build`؛ لا تحرره يدويًا.
One line per power, tool and superpower: where it lives, its badge, requirements, superpower, its family's tools, chapter and library card. Generated by `python3 scripts/micro_index.py build`; do not edit by hand. A line is an address, not a proof: ✅ still needs a real run.

## البحث / search

```bash
python3 scripts/micro_index.py find "قص على الإيقاع"          # any words, Arabic or English
python3 scripts/micro_index.py find "lufs" --kind tool
python3 scripts/micro_index.py show SP-0001                  # a superpower with its members and links
python3 scripts/micro_index.py show TRANS-12                 # a power with its superpower, tools and chapter
```
