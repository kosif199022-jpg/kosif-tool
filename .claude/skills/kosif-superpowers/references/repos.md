License notes / ملاحظات الترخيص: **permissive** (106) · **model/weights license: check commercial terms** (6) · **copyleft: run as an external tool, do not vendor** (5) · **custom: read before use** (4) · **weak copyleft** (4)

- *permissive* — MIT/Apache/BSD-style: may be installed, imported and shipped with credit.
- *weak copyleft* — LGPL/MPL-style: link or run as-is, publish changes to the library itself.
- *copyleft: run as an external tool, do not vendor* — GPL/AGPL: call the CLI, keep its source outside your film's code.
- *model/weights license: check commercial terms* — code may be open while weights carry use restrictions; read before commercial delivery.
- *custom: read before use* — bespoke terms (for example proprietary plugins next to an open core).

<details><summary>Caveats / محاذير</summary>

- **yt-dlp** — Needs ffmpeg for merging/conversion; site extractors break often so update frequently; only fetch content you are licensed to use; some bundled binaries are GPLv3.
- **PaddleOCR** — Heavy install (PaddlePaddle framework, large model downloads); CPU works but GPU is faster; Arabic recognition is weaker than Latin on stylized or connected display fonts.
- **OpenCV** — Wheel is ~60 MB; codec support depends on the bundled FFmpeg build; no Arabic text shaping in its drawing API; GPU optional, CPU path is deterministic.
- **MediaPipe** — Heavy wheel plus model downloads; CPU works but is slow on long clips; results are mostly deterministic per version; legacy Solutions API deprecated in favor of Tasks API.
- **Real-ESRGAN** — PyTorch install is heavy; fast only with GPU; portable binary lacks outscale and tiling can seam; hallucinated detail is non-deterministic across hardware; AI-reconstructed Arabic text may distort.
- **rembg** — Default bria-rmbg weights (~1 GB) need a paid license for commercial work; pick u2net for free use. Python 3.11-3.13, onnxruntime; GPU optional. Cloud providers upload images.
- **SAM 2 (Segment Anything Model 2)** — Heavy: PyTorch 2.5+, CUDA GPU and nvcc for the custom kernel; checkpoints are hundreds of MB; masks need edge cleanup; no CLI, Python only.
- **ImageMagick** — Distro packages often ship v6 (use convert, not magick); security policy.xml may block PDF/text; Arabic text rendering needs Pango/RAQM delegates; deterministic and CPU-only.
- **Color Thief** — Node path depends on sharp (native binary download). Palette is a median-cut quantisation, so results vary with sample size; no video decoding, sample frames first.
- **Depth Anything V2** — PyTorch install is heavy; GPU recommended for Large. Only the Small checkpoint is Apache-2.0; Base/Large are non-commercial. Output is relative depth, not metric.
- **PySceneDetect** — Pulls in OpenCV and needs ffmpeg for splitting; CPU-only and deterministic; detectors miss slow dissolves unless thresholds are tuned; no text or language dependency.
- **GPAC / MP4Box** — Native C build; distro packages often lag behind the DEV branch. LGPL is fine as an external CLI. No Arabic concerns; overlaps with ffprobe for basic checks.

</details>

- **Anime.js** — Pause autoplay and drive with seek() for deterministic renders; v4 API differs from v3 snippets; no built-in Arabic shaping, so split words not letters.
- **PixiJS** — Needs a GPU-capable headless browser; built-in text is LTR-oriented, so shape Arabic via HTML/canvas overlay or pre-rendered glyphs; randomness must be seeded for determinism.
- **Motion** — Real-time spring/WAAPI animations are wall-clock driven; for deterministic Remotion renders sample springs by frame or use its frame-based helpers instead of auto-playing transitions.
- **Lottie Web** — Needs assets authored in After Effects or LottieFiles; some AE effects unsupported; pass isFrame=true to goToAndStop and disable autoplay for deterministic scrubbing; large open-issue backlog.

- **Vivus** — Strokes only, not fills; paths need stroke attributes and converted text (outline Arabic glyphs first). Non-scaling strokes require recalc. Low-activity project but stable.
- **Theatre.js** — Studio package is AGPL: use it as a dev-time editor only, ship core. 1.0 development moved to a private repo, so public commits are sparse. No Arabic-specific features.
- **chroma.js** — Tiny pure-JS install, deterministic output, no GPU; color math only, no Arabic concerns. Contrast helper is WCAG 2 ratio, not APCA.
- **Flubber** — Last release 0.3.0 and sparse maintenance; only single closed rings per shape (no holes), so compound glyphs must be split; lower maxSegmentLength costs CPU.
- **gl-matrix** — Pure math only, no renderer or timeline; column-major Float32Array output must be mapped to CSS order; no releases listed on GitHub, so pin the npm version.
- **simplex-noise.js** — Tiny install; CPU-only and fast. Default Math.random is not reproducible, so always pass a seeded PRNG (alea) for deterministic frame renders. Noise is the raw math; no built-in fBm octaves.
- **bezier-easing** — Input clamped to 0..1, so no CSS-style overshoot; only cubic-bezier curves (no spring or step easings); maintenance activity is light.
- **dotlottie-web** — Needs the WASM binary served locally for offline renders; feature parity with lottie-web is not total.

<details><summary>Caveats / محاذير</summary>

- **three.js** — Needs GPU or SwiftShader headless; avoid requestAnimationFrame clocks for determinism; Arabic 3D text needs shaped glyphs (e.g. via opentype/Harfbuzz) since TextGeometry does not shape.
- **React Three Fiber** — Disable the internal clock and useFrame animation for deterministic renders; headless Chrome needs GPU or SwiftShader; v8 pairs with React 18, v9 with React 19; Arabic 3D text needs shaped glyph geometry.
- **Babylon.js** — Large bundle (several MB); needs GPU/WebGL in headless Chrome for frame capture; use fixed deltaTime for determinism; 3D text needs a font JSON; Arabic shaping must be handled upstream.
- **Blender** — Multi-hundred-MB install; Cycles is slow without a GPU, EEVEE needs OpenGL/Vulkan. Text objects lack RTL shaping, so pre-shape Arabic or import SVG outlines. GPL: keep external.
- **drei** — Heavy dependency tree and GPU-bound; frame-based rendering needs useFrame tied to Remotion frames for determinism; Text3D needs a font JSON, Arabic shaping requires a pre-shaped font or harfbuzz step.
- **Rapier** — Determinism holds only with the same build and fixed timestep; WASM init is async, so bake before capture starts.
- **postprocessing** — Needs a GPU-backed WebGL context in the headless renderer; three is a peer dependency with version coupling; use HalfFloatType buffers for bloom; no Arabic-specific concerns.
- **Troika (troika-three-text)** — Layout and SDF generation are asynchronous in a web worker: wait for sync before capturing frames. No WOFF2; fallback fonts fetched from CDN; needs WebGL.

<details><summary>Caveats / محاذير</summary>

- **Mermaid** — mermaid-cli pulls Puppeteer/Chromium (heavy install); auto-layout is not pixel-controllable; RTL Arabic labels need manual direction and font tweaks; SVG ids vary between versions.

- **React Flow / Svelte Flow (xyflow)** — Interactive library, not frame-aware: disable dragging/zoom and compute positions deterministically; auto-layout needs dagre or elkjs; RTL labels need custom nodes with dir=rtl.
- **plotly.js** — Heavy bundle (~3-4 MB); WebGL traces need a GPU-capable headless browser; built-in transitions are time-based, so set data per frame for deterministic renders; RTL labels need manual font setup.
- **deck.gl** — Needs a WebGL2-capable browser/GPU for headless capture; frame-stepping requires driving time manually for deterministic renders; Arabic labels depend on the basemap font stack.
- **Vega** — PNG export needs node-canvas native build (Cairo); exports are static frames, so animation is done by interpolating specs or SVG. Arabic text works only with RTL-aware fonts configured.
- **MapLibre GL JS** — Needs a WebGL-capable headless browser for rendering; tile sources load asynchronously, so wait for idle before capturing each frame; Arabic shaping requires the separate RTL plugin.
- **Cytoscape.js** — Force layouts are randomized; fix seeds or precompute positions and disable built-in animation for repeatable frames. Canvas text needs explicit Arabic font and RTL label handling.
- **world-atlas** — Natural Earth boundaries are a political choice: check disputed borders for the client's market; Arabic labels need your own names table.

- **SciPy** — Heavy wheel; keep numpy versions aligned; not a substitute for ffmpeg loudnorm on the final mix.
- **edge-tts** — Needs internet; relies on an unofficial Microsoft endpoint that can change or throttle. Boundary offsets are in 100-nanosecond ticks; convert to seconds. Custom SSML removed. Not for final commercial voice-over without…
- **Piper** — piper-tts PyPI package is GPL-3 in some releases while the repo is MIT; voice models carry their own licences; Arabic needs diacritised input for correct vowels.
- **Silero VAD** — Requires torch (heavy install) or ONNX Runtime; CPU is enough; language-agnostic so Arabic is fine; a README badge mentions CC BY-NC, verify LICENSE file before commercial use.
- **Demucs** — Archived Jan 2025 (maintained fork at adefossez/demucs); pulls PyTorch plus ~80MB-per-model weights; CPU separation is slow, GPU recommended; language-agnostic so Arabic vocals work fine.
- **pydub** — Requires a separate ffmpeg install; maintenance is slow with many open issues; silence detection is threshold-based (pydub.silence), not perceptual loudness; no built-in LUFS normalization.
- **librosa** — CPU-only, deterministic; pulls NumPy/SciPy/numba (~100 MB); needs ffmpeg or soundfile for mp3; no speech-to-text or word timestamps, analysis only.
- **Pedalboard** — GPL-3: use as a tool, never import into shipped code; VST hosting needs the plugins installed locally.
- **python-soundfile** — No MP3/AAC decoding on older libsndfile builds: route compressed audio through ffmpeg first.
- **pyloudnorm** — No true-peak limiter: pair with a limiter or ffmpeg loudnorm; short clips (<3 s) give unstable readings.
- **CTC Forced Aligner** — Needs FFmpeg, PyTorch and a model download; CPU works but slow. Default MMS model is CC-BY-NC, swap in an Arabic wav2vec2 model for commercial films; Arabic requires --romanize.

</details>

- **Lucide Icons** — Lightweight and deterministic. Icons are 24px stroke-based with no fill variants; directional icons (arrows, chevrons) need manual mirroring for RTL. No Arabic-specific glyphs.
- **Lenis** — Set autoRaf false and feed fixed frame times for deterministic renders; defaults to vertical only; RTL/Arabic layouts need horizontal direction checks; no GPU needs.

- **Iconify** — Default web component fetches icons from the public API at runtime; for deterministic offline renders install @iconify-json/* sets locally. Each icon set keeps its own license (check attribution).
- **Style Dictionary** — Repo moved from amzn to its own org; v4+ is ESM-only. Token JSON must follow its nesting convention; STYLE.json likely needs a small mapping step first.
- **Capsize** — Metrics package covers Google Fonts; custom or Arabic display fonts need fromFile/fromBlob extraction first.
