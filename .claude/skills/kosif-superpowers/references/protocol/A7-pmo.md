### -1.13 مكتب الإدارة الذكي KOSIF PMO / Executive Planning

(v5.3: سقالة قابلة للتشغيل: `think.py plan "<الهدف>" --weeks N` — مراحل عكسية وWBS وأسئلة premortem وشروط إيقاف.) عند إدارة مشروع طويل أو عدة وكلاء ومستودعات وموارد، اجمع مهارات Product Strategy وAgent Contracts وEngineering Reliability بحسب الحاجة، **ضمن سقف الحزم ذاته**.

| الجزء | المخرج الواجب |
|---|---|
| Project Charter | هدف واضح، جمهور، حدود النطاق، تعريف النجاح، ما لن يُنفذ، مسؤول القرار. |
| WBS | مهام صغيرة بمخرجات قابلة للفحص، معرف واحد، صاحب تنفيذ واحد، تبعيات واضحة. |
| Critical Path | ترتيب التبعيات والمسار الحرج وأول نموذج end-to-end واختبارات كل مرحلة. |
| RACI | منفذ ومراجع وصاحب اعتماد ومالك الأداة؛ التفويض لا يخلق صلاحيات. |
| Budget | تكلفة ووقت كـ«تقدير» حتى القياس، سقف صرف موافَق عليه، تنبيه مبكر، بديل أرخص. |
| Risk Register | خطر، سبب، أثر، اختبار كشف مبكر، وقاية، بديل، شرط إيقاف. |
| Change Control | مقارنة نطاق/تكلفة/ملفات، موافقات للدمج والنشر والتغيير غير القابل للرجوع. |
| QA & Delivery | حالات planned/running/blocked/produced/tested/verified/delivered مع مراجع أدلة. |

**قواعد الإدارة:** لا يكتب وكيلان الملف نفسه بالتوازي. احتفظ بمخرجات الوكلاء الناجحين عند فشل زميلهم؛ أعد الفاشل مرة واحدة بعقد أصغر، ثم صنّف الفشل. لا توزّع ألف وكيل لمجرد عددهم؛ قِس استقلالية الملفات والميزانية والموارد. سجّل القرارات والافتراضات والمخاطر المفتوحة وما يجب فعله تاليًا. احتفظ بعزل tenant/project؛ لا مشاركة معرفة أو مستندات شركتين تلقائيًا. أنشئ لوحة موجزة تقول «ما تحقق فعلاً» لا نسبة إنجاز مبنية على التخمين.
