# A46 — Suno MCP أول خطوة في الإقلاع

> **متى تقرأه / when to read:** أول خطوة في كل محادثة (سطر `suno:`)، أو أي أغنية أو موسيقى أو صوت · [العودة إلى النواة / back to the core](../../PROTOCOL.md#متى-تفتح-الملاحق--appendix-triggers)

**الطلب (30-10-2026):** «https://api.suno.com/mcp اضف ان يتم الاتصال به في اول شيء».
**القاعدة:** قبل تحديد الوضع وقبل أي طلب، Claude يتأكد إن Suno MCP متصل، ويكتب النتيجة في سطر واحد. لو مش متصل، يقول إزاي يتوصّل ويكمّل الشغل عادي (الاتصال ما يوقفش أي مهمة مش محتاجة موسيقى).

## 1. اللي اتقاس من السيرفر (بدون تسجيل دخول)

الدليل الخام: `evidence/A46-suno-mcp-probe.txt` (بجانب هذا الملف).

| السؤال | النتيجة |
|---|---|
| العنوان | `https://api.suno.com/mcp` (MCP عبر HTTP) |
| من غير دخول | `401` و`{"error":"sign in to Suno to use this server"}`، حتى طلب `initialize` نفسه |
| نوع المصادقة | OAuth 2.1 (Bearer في الهيدر). **مفيش API key**: الدخول بحساب Suno نفسه |
| سيرفر المصادقة | `https://studio-api-prod.suno.com/api/v2/external/oauth` (PKCE S256، تسجيل عميل ديناميكي، و`client_id_metadata_document_supported`) |
| الصلاحيات اللي السيرفر بيطلبها | `profile:read`، `library:read`، `library:search`، `library:write`، `download`، `credits:spend`، `api:v0`، `offline_access` |
| قايمة الأدوات | **مش مقيسة**: السيرفر ما بيرجعش `tools/list` قبل الدخول. أول جلسة متصلة تكتبها هنا |
| في دليل connectors بتاع claude.ai | **لأ** (بحث `suno` في السجل رجع Sonos وSpotify بس) ← يتضاف كـ custom connector |

معنى `credits:spend`: الأدوات تقدر تصرف رصيد Suno. فكل توليد بإذن (القاعدة 3 تحت).

## 2. إزاي يتوصّل (مرة واحدة لكل بيئة)

| البيئة | الخطوات |
|---|---|
| **claude.ai / التطبيق / الموبايل / الجلسات السحابية** | Settings ← Connectors ← **Add custom connector** ← الاسم `Suno` والعنوان `https://api.suno.com/mcp` ← Add ← Connect ← سجّل دخول Suno ووافق. بعد كده يظهر في كل محادثة وجلسة جديدة (Connectors مش بتتفعّل لكل محادثة لوحدها). |
| **Claude Code على جهازك** | `claude mcp add --transport http suno https://api.suno.com/mcp` ثم جوه Claude Code: `/mcp` ← suno ← Authenticate (بيفتح المتصفح لدخول Suno). |
| **Claude Desktop** | نفس طريقة claude.ai (Settings ← Connectors ← Add custom connector). |

- مفيش مفتاح يتنسخ، ومفيش توكن يتكتب في ملف أو سجل أو commit. التوكن بيفضل عند العميل.
- لو الحساب Team/Enterprise وزرار Add custom connector مش ظاهر: الأدمن لازم يضيفه.

## 3. الخطوة صفر (اللي Claude يعملها في أول رد)

1. دوّر في أدواتك على أي أداة اسمها فيه `suno` (مثلًا `mcp__suno__*` أو `mcp__Suno__*`).
2. **لقيتها:** نادِ أداة قراءة بس، بلا رصيد (البروفايل أو المكتبة) لو موجودة. نجحت ← `suno: متصل ✅`. رجعت 401 أو انتهى الدخول ← `suno: الدخول منتهي 🔑 — أعد الاتصال من Settings ← Connectors`.
3. **مالقيتهاش:** `suno: غير متصل 🔑 — ضيفه: Settings ← Connectors ← Add custom connector ← https://api.suno.com/mcp`. ولو البيئة فيها أداة اقتراح connectors، استعملها.
4. **الوضع 3 (بلا أدوات):** `suno: مش مقيس من هنا`.
5. السطر ده **قبل** سطر الوضع، وفي نفس الرد. ما تسألش عنه، ما تستناش، وكمّل الطلب.
6. أول مرة يتصل فعلًا: اكتب أسماء أدواته ووصف كل واحدة في القسم 1 هنا (أو في سجل المهمة)، عشان الجدول يبقى مقيس مش متوقع.

## 4. قواعد الاستخدام

1. **أغنية أو موسيقى أو صوت لإعلان/فيديو/موقع:** Suno هو الأول لو متصل.
2. القراءة (البروفايل، المكتبة، البحث، التنزيل لملفاتي) مسموحة من غير سؤال.
3. **التوليد أو أي أداة بتصرف credits:** اعرض البرومبت (الستايل والكلمات والمدة) والتكلفة لو الأداة بتقولها، وخد موافقتي الأول. نفس قاعدة رصيد Higgsfield.
4. «اتعملت» بس لما يرجع ملف أو رابط من الأداة، وفي الإيصال: معرّف الأغنية والمدة والرابط.
5. الملكية والترخيص حسب خطة حسابي في Suno: ما تقولش «مسموح تجاريًا» من غير ما تتأكد من الخطة.

## 5. البديل لو Suno مش متاح

بالترتيب، ومن غير ما توقف المهمة:
1. `generate_audio` في Higgsfield MCP لو متصل، بنفس قاعدة إذن الرصيد.
2. موسيقى مرخّصة مجانًا (مكتبة YouTube Audio، Pixabay Music) مع اسم المصدر والترخيص.
3. سيب مكان الموسيقى فاضي في التايملاين واكتب «مستني Suno» في التسليم.
