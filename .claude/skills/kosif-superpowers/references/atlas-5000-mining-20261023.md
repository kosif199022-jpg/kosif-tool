## What the 5000 atlas is

[KOSIF Atlas](https://github.com/kosif199022-jpg/kosif-atlas) (commit `99bb108d`) mirrors **14,793** third-party skills (14,708 permissive and 85 copyleft). Its safe core, the skills with the KOSIF inspection verdict `READ_ONLY_OK`, a permissive license and no risk flags, is **5,116** skills. That safe core is what "أطلس الـ5000 مهارة" refers to, and it is the only part mined here. The private mirror `kosif-atlas-private` (6,426 skills with restricted, unknown or blocked licenses) was not used for any card.

## How to use it

    python3 scripts/atlas_5000.py stats                       # coverage per theme
    python3 scripts/atlas_5000.py gaps --top 8                # what is still missing, with candidates
    python3 scripts/atlas_5000.py find "رسم ويبتون بشخصية ثابتة" --top 10
    python3 scripts/atlas_5000.py find "secret scanning" --uncovered
    python3 scripts/atlas_5000.py show 2425 --json
    python3 scripts/powers.py show ACRAFT-10                  # the distilled method itself

To mine the next batch: pick candidates from `gaps`, read each `SKILL.md` in a local Atlas checkout as text, paraphrase the method into a power record in the matching `atlas-*` family with its proof URL, license and source hash, then run the build chain in `guides/maintain.md`.

## Boundaries

- Every card paraphrases a method; no Atlas script, package, prompt or instruction was executed, installed or copied verbatim.
- `documented` is the honest badge: nothing here was run on this host. A card about FFmpeg, Godot or After Effects still needs that tool installed and a real test.
- Atlas themes come from a keyword taxonomy, so some skills are misfiled (for example a webtoon skill under video-motion).
- Covered does not mean the whole skill was absorbed, only that one card cites it.
