# KOSIF Timeline v1 — محرر الفيديو والصور والصوت متعدد المسارات

**أداة تشغيلية مستقلة** تعتمد على FFmpeg وPython/Pillow. ليست نسخة من Canva أو Premiere، ولا تتضمن أي شيفرة أو ملفات مملوكة لهما، وليست حتى الآن محررًا رسوميًا بالسحب والإفلات.

## الوظائف التي تم تشغيلها واختبارها

- مشروع قابل للتعديل بصيغة kosif.timeline.v1 يحتوي على tracks وclips؛ كل مسار من نوع video أو image أو audio، بترتيب layer قابل للضبط.
- يحدد كل مقطع source path وstart على التايملاين وin (نقطة بدء المصدر) وduration، بالإضافة إلى fade_in وfade_out وvolume. عناصر الفيديو والصور لها x/y/width/height، وتسمح مقاطع الفيديو بـinclude_audio.
- تركيب مقاطع الفيديو والصور باستخدام FFmpeg trim وsetpts وscale وpad وoverlay وfade مع توليد MP4 H.264؛ تداخل المقاطع مع fades ينفّذ انتقال تلاشي بسيط، وليس انتقالًا حركيًا متقدمًا.
- قص ودمج الصوت مع تأخير زمني وموازنة مستوى الصوت ثم تصدير AAC. الملف المصدر لا يُكتب عليه.
- أوامر edit لا تغيّر الأصل: move لتغيير البداية، trim لتحديد الفترة المستخدمة، fade لضبط التلاشي. كل تعديل ينتج **ملف مشروع JSON جديدًا**.
- undo وredo يعملان على سجل حتى 10 لقطات من حالة المسارات داخل ملفات المشروع، وليسا تراجعًا عن ملف فيديو أُنتج سابقًا.
- FFprobe للتحقق من عدد الإطارات والأبعاد والمسارات وترميزات الإخراج؛ استلام بصمة SHA256 بعد التصدير.

## أوامر الاستخدام

من مجلد .claude/skills/kosif-superpowers على الكمبيوتر:

1. python scripts/kosif_timeline.py doctor
2. python scripts/kosif_timeline_demo.py --dir "C:\Users\Public\KOSIF-TIMELINE-DEMO-NEW"
3. python scripts/kosif_timeline.py check --project "C:\Users\Public\KOSIF-TIMELINE-DEMO-NEW\project.json"
4. python scripts/kosif_timeline.py render --project "C:\Users\Public\KOSIF-TIMELINE-DEMO-NEW\project.json" --output "C:\Users\Public\KOSIF-TIMELINE-DEMO-NEW\my-export.mp4"

مثال نسخة مشروع جديدة لتحريك طبقة الرسم:
python scripts/kosif_timeline.py edit --project project.json --operation move --clip badge --start 0.6 --output moved.json

التراجع:
python scripts/kosif_timeline.py undo --project moved.json --output reverted.json

إعادة التعديل:
python scripts/kosif_timeline.py redo --project reverted.json --output reapplied.json

لا تكتب على ملف خرج موجود. غيّر source path في المشروع إلى ملفات الفيديو والصور والصوت الخاصة بك أو المرخّصة لك، ولا تشغّل ملفات تطبيقات تجارية كمقاطع.

## مصفوفة القدرات والحدود

| القدرة | الحالة |
|---|---|
| فيديو وصوت وصور في مسارات متعددة | مطبقة ومختبرة |
| قص مصدر المقطع وتحريكه زمنيًا | مطبقة ومختبرة |
| طبقات وترتيب خلفية/مقدمة | مطبقة ومختبرة |
| تلاشي دخول وخروج وتداخل المقاطع | مطبقة ومختبرة |
| مساران صوتيان ومزج بمستويات مستقلة | مطبقة ومختبرة |
| Undo / Redo لمشروع JSON | مطبقة ومختبرة |
| فحص مشروع 9:16 بدقة 1080×1920 | تم اختبار التحقق من البيانات؛ لم يتم تصدير فيديو بهذه الدقة |
| تصدير MP4 بفيديو H.264 وصوت AAC | مطبق ومختبر |
| واجهة Timeline رسومية بالسحب والإفلات | لم تُنفذ بعد |
| مفاتيح الحركة ومزامنة الكلمات والترجمة | ليست جزءًا من هذا المحرك بعد |
| التقاط مباشر للشاشة أو الكاميرا | غير منفذ في هذا المحرك |
| التعديل اللوني والأقنعة وتتبع الحركة | يحتاج ربط الأدوات الأخرى بالمحرك |

الحدود: مدة المشروع بحد أقصى 60 ثانية، 1–30 FPS، حتى 32 مقطعًا و12 مسارًا؛ أبعاد زوجية حتى 1920×1920 بميزانية لا تزيد عن 300 مليون pixel-frame. الحد الأقصى لحجم ملف المصدر 1GB؛ يجب أن تكون ملفات المصدر محلية بالامتدادات المحددة، وتفحص مدة كل مصدر ومسار الوسائط قبل الرندر. التنفيذ لا يستخدم نص أوامر shell من المستخدم، وإنما وسيطات منفصلة. الصوت الناتج AAC معاد الترميز وقد يختلف على مستوى العينات. توقيت الفيديو مُقرب إلى الإطارات، والطبقات تستخدم موضعًا ثابتًا فقط.
