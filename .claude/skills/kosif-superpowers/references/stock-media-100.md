# KOSIF Superpowers — 100 media discovery websites

**This is a discovery index of 100 distinct domains, NOT a claim that all content on 100 sites is copyright-free or commercially reusable.** Many sites contain mixed-license media. Always open the individual asset's license or permission and retain evidence before editing. Some sources provide public-domain material only in the United States; privacy, brand, trademark and music rights may remain.

Recommended selection: prefer **CC0** or public-domain items with a checked jurisdiction, then **CC BY** with exact credit, then reviewed **CC BY-SA** with derivative-license obligations, and properly licensed stock footage. Exclude NC (noncommercial) for commercial projects, and ND (no derivatives) for edits. Never rely solely on search filters.

## Usage and evidence

```bash
# From the repository root:
python3 .claude/skills/kosif-superpowers/scripts/media_sources.py list
python3 .claude/skills/kosif-superpowers/scripts/media_sources.py search pixabay
python3 .claude/skills/kosif-superpowers/scripts/media_sources.py search --type video_image
python3 .claude/skills/kosif-superpowers/scripts/media_sources.py plan 'https://example.org/clip'

# Video you own:
python3 .claude/skills/kosif-superpowers/scripts/media_sources.py download 'https://example.org/my-video.mp4' --rights owned -o project/assets

# A verified CC BY item with retained item license evidence:
python3 .claude/skills/kosif-superpowers/scripts/media_sources.py download 'https://example.org/allowed-video.mp4' --rights cc-by --creator 'Creator' --credit 'Creator — CC BY 4.0' --evidence-url 'https://example.org/asset/license' -o project/assets
```

The download command uses existing `scripts/fetch_video.py` (`yt-dlp`, plus optional ffmpeg) and creates `asset_rights.jsonl` with the editing-file path, SHA-256, creator, rights claim and license evidence URL. It cannot prove a claim is true; the operator must inspect the item. The `--safe` edit-friendly MP4 default can be disabled with `--no-safe`.

**Cinema C V34 for iPhone:** `tools/a-shell/Cinema_C_V34_Studio_iPhone.sh` supports `c --batch`, `c --studio` and Photos-safe output. The CLI gateway is intended for desktop/Claude Code; use a-Shell directly on iPhone.

**Do not** bypass DRM, account permissions, paywalls, geographic restrictions, CAPTCHA or platform terms; don't claim that downloads from every site work. An item may be free of copyright but still have publicity, trademark, property or music restrictions. Never redistribute unchanged stock as a competing catalog.
