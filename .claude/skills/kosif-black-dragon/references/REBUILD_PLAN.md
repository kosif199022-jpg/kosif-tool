## الهدف: مستودع واحد نضيف
```
black-dragon/
  dragon/                 الحزمة الأساسية (Python، من غير تبعيات تقيلة)
    catalog.py            يجمع كل المهارات والأدوات والقدرات من كل المستودعات في SQLite FTS5 واحد
    arabic.py             توحيد العربي للبحث (الألف والياء والتاء المربوطة والتشكيل)
    router.py             طلب بكلام المستخدم → مهارات وأدوات وقدرات مرتبة
    doctor.py             فحص البرامج والمكتبات المطلوبة فعليًا
    verify.py             قياس أي ناتج (فيديو وصوت وصورة)
    ledger.py             التعلّم من النتايج
    cli.py                الأمر الواحد: python -m dragon ...
  engines/                المحركات المتخصصة، كل واحد مستقل وليه اختبارات
    cinema/               خط «سينما الفوتيج» المجرّب (أفلام ميار)
    render/               رندر HTML→MP4 (نقل وتبسيط render_html.cjs)
    audio/                بيت، وكلمات، وتوقيت كلام، وducking، وLUFS
    montage/              عمليات ffmpeg (قص ذكي، ودمج، وريفريم 9:16)
    image/                عمليات الصور والنص العربي
  data/                   البيانات بس (JSON وSQLite متولّدة)، مفيش بيانات جوه الكود
  skills/black-dragon/SKILL.md   باب واحد لكل حاجة
  tests/                  pytest لكل وحدة، واختبارات «ذهبية» على ميديا حقيقية
```
