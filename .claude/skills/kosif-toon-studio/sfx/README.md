# Sound effects (not included in the zip)

The engine expects these MP3 files in this folder, or in a folder named by the `TOON_SFX` environment variable:

| Group | Files |
|---|---|
| Laughs | laugh_cartoon, laugh_cartoon2, laugh_male, giggle, giggle_kid |
| Rain and weather | rain_light, rain_storm, thunder_close, thunder_mid, thunder_impact, wind_storm |
| Water | pour, splash_big, bubble, bubbles_deep, fill, river, drips |
| Other | birds_river, explosion, whoosh, pop, clink |

Source: https://mixkit.co/free-sound-effects/ (Mixkit Free License: free, including commercial use, no attribution needed, but the files may not be re-shared on their own, which is why they are not in the zip).

Download a fitting sound for each name and save it as `<name>.mp3`.

A missing effect does not break the render: it is silent, and a warning is printed.
